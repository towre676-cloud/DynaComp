# Engineering ingestion and replay, version 0.12.0

The compiler accepts real descriptor equations `E x_next = A x + B u` in discrete mode and `E x_dot = A x + B u` when a positive rational sampling interval is supplied. In either case the engineering output is `y = C x + F u`; the MAT file names F as D. The reduction already uses D for its reduced output matrix, so engineering feedthrough lives in the workload's separate `feedthrough` field. State coordinates, initial boxes, input channels, and output rows retain their original meanings. The importer requires explicit A, B and C rather than inventing an output from B. MAT finite binary64 entries are bound as exact dyadics; integer entries remain exact integers. Sparse MAT storage is accepted and converted to the existing dense workload route.

## Descriptor elimination

For a nonsingular mass matrix, solving `E As = A` and `E Bs = B` gives standard dynamics without changing coordinates. General masses through 32 states are eliminated using rational inversion. Arbitrarily sized diagonal masses use exact coordinate division and reject zero diagonal entries. General masses through 256 states can alternatively be accepted by strict row diagonal dominance. Let `mu = min_i (|Eii| - sum_{j != i}|Eij|) > 0`. If |v_i| is a maximum component of a nonzero v, then `|(Ev)_i| >= mu ||v||inf`. Thus E is nonsingular and `||E^-1||inf <= 1/mu`. A numerical solve only proposes stored As and Bs. Exact rational replay computes residuals and proves `||As - E^-1 A||inf <= ||E As - A||inf / mu`, with the analogous bound for Bs. The proof does not depend on LAPACK reporting success or on a floating condition estimate.

Above these limits, or when the sufficient dominance test fails, the importer refuses the mass rather than approximating a descriptor differential-algebraic equation. A refused mass can be nonsingular: refusal identifies the supported proof route, not a false theorem of singularity. General small singular masses and diagonal masses with a zero diagonal are explicitly rejected. NaN, infinity, complex entries, inconsistent E/F dimensions and missing output matrices are rejected before conversion.

## Continuous sampling enclosure

For exact standardized coefficients and rational interval h, form `M = h [[As,Bs],[0,0]]`. Zero-order hold gives the A and B blocks of exp(M). SciPy expm proposes the stored coefficients but supplies no proof premise. At augmented dimension at most 12 and infinity norm at most 8, the verifier independently constructs `Pk = sum_{j=0}^k M^j/j!` over the rationals. For `rho = ||M||inf` and `k+2 > rho`, the tail obeys `||exp(M)-Pk||inf <= [rho^(k+1)/(k+1)!]/[1-rho/(k+2)]`, since each successive absolute series term has ratio at most rho/(k+2). The verifier stops when this tail is at most 2^-100, within 160 terms. Row discrepancies between Pk and the stored A/B blocks are included before positive bounds are rounded outward. Errors in rounding h, input loading into expm, and expm itself are consequently covered by the final coefficient discrepancies.

Larger augmented dimensions, larger norms and continuous sampling following residual-bounded descriptor elimination are explicitly `uncertified`. Such workloads may still compile against their exact stored sampled coefficients. They receive no continuous-time claim. `import-mat --require-bounded` refuses these cases. This distinction is recorded in `import_certificate.transformation`, replayed during workload loading, and reported in saved plans and evaluation results. This release does not provide continuous intersample bounds, arbitrary time-varying inputs within a sampling interval, physical calibration bounds, or a Lean theorem for the new verifier.

## Propagating transformation error

Suppose coefficient errors are bounded in infinity norm by da and db. For stored sampled coefficients, let `X0 = max_i(|center_i| + radius_i)` and `Ut = max_i(|input_center_ti| + input_radius_ti)`. A sufficient stored-source state envelope is `Xnext = ||As||inf X + ||Bs||inf U`. Starting at error e0 = 0, a bound against the original descriptor or exact ZOH samples is `enext = (||As||inf + da)e + da X + db U`. For output row c, the extra error is `||c||1 e`. Each positive envelope is evaluated rationally and rounded outward. The recurrence is valid without assuming stability and may therefore be conservative over long horizons or strongly nonnormal sources. It uses the actual supplied boxes and horizon; changing them forces reconstruction.

## Feedthrough and executable outputs

Inputs have the existing shape `[T,m,queries]` and outputs retain shape `[T+1,p,queries]`. The declared convention is right-continuous held inputs: output at sample t<T uses u[t]; the terminal sample uses u[T-1], extending the final hold through that endpoint. This is explicit in `output_input_semantics`, not an implicit one-step delay. A nonzero F requires at least one input interval; other endpoint conventions are refused. There is no invented u[T]. Initial feedthrough depends on u[0] and is therefore not folded into the state encoder.

The original C executor computes the reduced state output. A separate function in the same checked C library computes each F row dot in left-to-right order, with volatile product and accumulator stores, then performs one separately rounded addition to the base output. It retains the compiler flags, RN-even and gradual-underflow checks of the native executor. The original zero-feedthrough route returns the original base output unchanged. The full BLAS diagnostic adds F under its ordinary uncertified rounding semantics.

For loaded feedthrough Fhat and exact admitted input envelope U, let `M = sum_k |Fhat_jk| U_k`. Loading and dot error are bounded by `sum_k |Fhat_jk-F_jk| U_k + sequential_budget(M,m)`. The separately rounded final addition is bounded by `u L + eta`, with L an absolute bound on the base native output plus the computed feedthrough. The base magnitude is bounded using the stored full source's state envelope plus the existing combined model/execution certificate. Intermediate dot and addition overflow is excluded before acceptance. This accounting includes output arithmetic even when the exact feedthrough cancels a large state output.

The saved plan retains a `dynacomp.engineering-output/1` contract, including loaded feedthrough words, per-time transformation bounds and total additional output bounds. Replay reconstructs it from the workload and the already replayable native composition. Acceptance checks the maximum of the time-matched native bound plus the engineering bound against the original workload tolerance. Evaluation and supplied-scenario simulation repeat that check and refuse altered summaries, feedthrough, domains, source matrices or endpoint semantics. Native packet schemas and the three original baseline artifacts are preserved. An individual native packet certifies only its stated state-output source; the engineering guarantee belongs to the bound workload and saved plan together.

Output normalization is opt-in. Its divisor is the exact maximum C-row absolute sum; both C and F are divided by the same rational value. The original matrices and divisor remain in the import certificate, so normalized units and physical units cannot silently diverge. The importer changes no default boxes or transition count: it retains the existing twenty-step exploratory contract, and actual engineering domains must be supplied before interpreting a result as an operating guarantee.

## Reproduction and publication

Install `.[numerical,test]` and a GCC-compatible compiler. Run `PYTHONPATH=src python -m unittest discover -s tests -v`. Acquire `https://github.com/SLICOT/Benchmark-ModelReduction`, checkout `98c1747030c0b1bf48d9353b2dcc9c4583867ca1`, then run `PYTHONPATH=src python benchmarks/engineering_ingestion.py --models PATH`. Omitting `--models` automatically acquires and checks out the pinned public collection. The script retains imported workloads, packets, plans, raw alternating timing trials, importer and replay costs, dense-versus-banded solve diagnostics and original-baseline acceptance comparisons. Feedthrough stress data are explicitly synthetic: they use a principal public mass block with supplied synthetic dynamics and F, and are not represented as an intact physical SLICOT model. The PEEC refusal is retained. Model file hashes bind the acquisition; original MAT bytes remain upstream.

The existing development history is the ancestor of this extension. Publishing on main uses a branch from that history and a normal non-force push, after fetching concurrent updates. The historical default branch remains available. Changing the GitHub default branch or creating a tagged Release is a separate repository administration step; this extension does not delete or overwrite earlier branches.


## Retained measurements on 12 October 2026

The public SLICOT heat-disc trial accepts nine observable states from 200 under a 0.01 absolute physical-output ceiling. The complete engineering upper bound is 0.00348327051844; the original-descriptor reference includes both mass elimination and native execution error. MAT ingestion including certification took 2.535 seconds; a separate import-certificate replay took 1.132 seconds. An ordinary uncertified dense reference solve took 0.001096 seconds, illustrating the certification overhead rather than hiding it. Native warm execution measured 4.500 times the full BLAS reference, with break-even at about 438.0 batches of 256 scenarios under the recorded setup accounting. These setup projections exclude initial MAT ingestion, which is reported separately; adding that cost increases deployment break-even. Balanced search did not meet the target in ranks one through sixteen and remains in the receipt.

The explicitly synthetic four-state feedthrough stress trial has a bounded ZOH transformation, took 0.0275 seconds to import and certify, and retains full timing and failure histories for both reductions. It tests the compiler and output semantics rather than establishing performance on an intact public feedthrough engineering model. No nonzero-feedthrough source was present among the inspected SLICOT MAT files, so that external empirical gap remains explicit.

All three original sampled-source regressions preserve accepted ranks and mathematical bounds exactly. New warm timing ratios for heat, convection and building are 6.759, 5.312 and 0.543. The original 5.89 heat ratio is historical; timing variation does not change its retained evidence. The building source remains slower than full BLAS, with no measured break-even. The full suite passes 229 tests; twelve focused importer/pilot tests also pass after final integration cleanup.
