# Four applications and their live research connection

PerfectPower answers finite questions by counting every possibility that satisfies the supplied rules. The simple packing example counts all subsets of six optional items with integer factor elimination and independently enumerates the same population. Empty selections count unless water is required. This demonstration does not benchmark the 0.10.2 native solver.

DynaComp follows a sampled linear system over time. It finds a smaller realization for a chosen output and compares it with the full trajectory. The browser runs the repository's Python modules in Pyodide 0.29.5 WebAssembly on the user's device. Teaching examples use illustrative units. Uploaded small sampled models retain descriptor transformations and direct feedthrough; continuous-time models are rejected rather than silently sampled. Exact fractions are retained in downloads. Approximation certificates apply to the displayed finite horizon and supplied initial/input box, not uncertainty in a physical system. Keeping fewer values is not a measured speedup.

NFL PerfectPower explains games, prices and scenarios. It retains its historical calibration and live sports sources. Its exact finite counter can receive compatible PerfectPower browser updates. Mathematical correctness of counting does not imply a forecasting or betting advantage. DynaComp updates are visible research information, not automatically used to replace the football prediction model.

Pokepolis is a Godot game for exploring a board, assembling a team and playing campaigns. Its Windows and Android download sites receive the shared research connection and app navigation. Existing Windows 0.15 and Android 0.16 binaries are preserved. Their executable gameplay is not replaced by a web research refresh.

## Download and update contract

The collection hub is https://our-apps.towre676.chatgpt.site . Each product has its own Site, clear purpose, download links and a route back to the collection. DynaComp is an installable home-screen web app, not an Android APK. PerfectPower and Pokepolis retain explicit native downloads. Full repository ZIPs include software, tests, worked receipts and mathematical explanations; a branch ZIP follows current main, while a commit ZIP is the immutable reproducibility route.

Both upstream main branches publish deterministic JSON envelopes. SHA-256 covers the exact payload string; individual DynaComp source files carry hashes. Hashes detect inconsistency, not an independent trust signature. Published GitHub main remains the trust root. Every app Site observes both research feeds and provides source links. Supported DynaComp Python/browser source and shared PerfectPower browser counter refresh automatically; custom models remain local. DynaComp calculations pin the source digest at launch, and exported results retain it even when a new feed arrives. Native binaries require explicit installation of a new package. Breaking feed/API contracts require consumer changes and deployment. Future upstream changes are not a promise that every engine or gameplay feature automatically benefits.

The server retains a verified bundled fallback when the public feed cannot be acquired, and reports live versus saved research. Active browser connections check every five minutes. The DynaComp service worker caches previously opened resources; first-time WebAssembly preparation needs a connection. Saved comparisons use device storage and can be exported as exact JSON. Site audiences are preserved.

## Verification and limits

DynaComp's full Python regression suite and browser-portable source execution are checked separately. Four actual WebAssembly runs compare warmth/supplies and whole-system/single-place outputs with zero exact difference. Explorer regression cases cover rejected continuous-time input, descriptor transformation and direct feedthrough. The simple PerfectPower demonstration verifies factor counts against enumeration. Existing download payloads remain intact.

Browser visual QA and a physical-phone installation test are unavailable in this managed environment. Successful Site publication verifies deployment, not a physical-device test. Native mobile upgrades were not rebuilt in this release. Historical PerfectPower benchmark claims remain historical; this integration does not reconstruct the missing complete 200-instance receipt archive or publish restricted materials.
