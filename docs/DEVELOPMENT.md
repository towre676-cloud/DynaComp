# Development scope

Version 0.6 supplies sharp approximate acceptance for independent box domains and arbitrary time-varying convex endpoint combinations. Commuting full/projected families use count-lattice dynamic programming; noncommuting cases use resource-limited word enumeration. Reusable numerical execution and exact directed membership checks improve repeated scenario workloads. See [SWITCHING.md](SWITCHING.md).

Version 0.5 joins general-direction enrichment with sharp box-uniform output-error acceptance, attaining witnesses, sparse coefficient-family closure and a thermal scenario workbench. See [UNIFORM.md](UNIFORM.md).

Version 0.4 adds Hankel-certified minimal realization, word-labelled switched closure, weighted automaton and HMM minimization and equivalence with shortest counterexamples, exact one-parameter rank-change loci, scenario-certified direction enrichment, controlled polynomial lifts and a heated-plate application; see [EXTENSIONS.md](EXTENSIONS.md).

Version 0.3 adds an inventory-network scenario application, compact aggregate plans, conservation accounting and optional vectorized batch execution. Version 0.2 implements exact observable compilation, uniform finite-horizon box bounds, greedy coordinate enrichment, least-cost bound-accepted subset search, coefficient-family closure, affine parameter conditions and minimal scalar output recurrences with input kernels. The imported release history is preserved. Every exact mechanism uses standard-library rational arithmetic; optional POD proposals remain numerical candidates.

General-direction enrichment beyond coordinate subsets is now implemented for linear models. Nonlinear features, auxiliary memory states and correlated or parameter-uncertain acceptance domains are the next representation fronts. Version 0.4 takes a first step: `greedy_enrichment` adds general rational directions (target-visible error snapshots and transition residuals), not only coordinates, but certifies supplied scenarios rather than a box domain. Version 0.5 now combines general directions with sharp fixed-model box acceptance. Time-varying convex parameter uncertainty is now covered in 0.6. Correlated domains, noncommuting long-horizon search, spatially uncertain coefficients and nonlinear approximation remain next fronts. Its acceptance route must state the initial-state domain, input class and time horizon. Numerical trajectory agreement alone is insufficient for a uniform claim.

The present common family encoding handles any finite collection of rational coefficient matrices and their time-varying linear combinations. Fixed-encoder closure conditions are affine in the declared parameters. General rank-change loci for one real parameter are now exact (0.4, `parametric_analysis`); several parameters, nonlinear parameter families and domain-dependent identities still need additional symbolic machinery. Family output preservation does not imply a uniform stability margin.

Scalar linear input/output memory is derived exactly. General nonlinear memory remains open: a projected variable can retain influence through hidden coordinates, and no universal finite delay length follows from finite training data. Polynomial examples with analytically derived closures should precede claims about arbitrary nonlinear simulations.

Cost-aware coordinate search optimizes only within the declared coordinate family and the conservative box-envelope acceptance criterion. Costs are supplied estimates, not automatically calibrated runtime measurements. Dense rational interval envelopes remain expensive at large state dimensions or horizons. Sparse target propagation and cached error kernels are now implemented for the sharp-box route, and target pullbacks replace full powers in the older scenario-bound routine. Very long rational horizons and validated floating-point bounds remain computational fronts.

The diagonal metric search is intentionally limited. General rational Lyapunov matrices, continuous-time generators, sparse semidefinite methods and switching stability need distinct acceptance routes. Numerical optimization can propose a metric; exact or validated numerical inequalities must establish its claimed margin.

The first application now covers fixed-fraction inventory routing, regional stock, dispatch and supplied replenishment scenarios. Its synthetic benchmark includes full SciPy sparse and hand-built aggregate baselines, construction amortization and a no-compression case. The thermal application now includes exact time-varying uniform-conductance families and sharp finite-horizon approximate population guarantees under changing conductance. Customer data, congestion, demand-limited dispatch, time-varying inventory routing and empirical logistics validation remain open. A physical application can also use a parameterized thermal or lattice-wave model with specified outputs and forcing domains. Compare full sparse evolution, established reduced-order methods and adaptive compilation at matched target tolerance, including construction, initial encoding and replay costs. The graphene Hamiltonian application will require correct complex arithmetic and unitary error analysis; neither is implemented here.

No general industrial speedup, new universal reduction theorem, automated physical-law discovery or Lean proof is claimed. The retained ring and inventory-network speedups are structured demonstrations, with the latter including an explicit first-batch loss and a full-size case. The new mechanisms broaden what can be constructed and what its guarantees cover; harder applications must establish their own performance evidence.
